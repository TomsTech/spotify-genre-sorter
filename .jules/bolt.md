## 2024-06-25 - Chunk concurrent KV calls to respect Cloudflare limits
**Learning:** Promise.all for external resources often lacks constraints. In Edge runtimes like Cloudflare Workers, a large unchunked `Promise.all` operation can easily exceed strict concurrent limits (like the 50 subrequests limit), leading to immediate runtime errors and crashed requests.
**Action:** When working with Edge runtimes (Cloudflare, Vercel Edge, Deno), proactively slice potentially unbounded arrays into safe batch sizes (e.g., 25-45) and use `await Promise.all()` within a sequential `for` loop to cap concurrency while preserving partial parallel performance.
